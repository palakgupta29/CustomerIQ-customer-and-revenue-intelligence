## Overall Learning 

During my internship, I gained practical knowledge in **Data Analytics, Python Programming, Object-Oriented Programming, NumPy, Pandas, SQL, Excel, Databricks, PySpark and Machine Learning**. The training combined programming exercises with practical data-analysis problems and project-based learning.

The internship helped me understand how to write structured programs, clean and validate datasets, identify patterns and anomalies, perform business analysis, and convert technical findings into meaningful insights.

### Key Learning Areas

* Python programming fundamentals and exception handling
* Object-Oriented Programming and reusable software design
* Numerical analysis with NumPy
* Data manipulation and analysis with Pandas
* Data cleaning and data-quality validation
* Retail revenue and transaction analysis
* NYC taxi fare and suspicious-trip auditing
* Excel-based data analysis and reporting
* Basic SQL operations
* Databricks and PySpark fundamentals
* Machine Learning and predictive modelling
* Streamlit application development
* Generative AI integration

### Python Programming

I learned variables and data types, conditional statements, loops, functions, lists, tuples, dictionaries, sets, and exception handling.

### Object-Oriented Programming

I learned classes and objects, constructors using `__init__()`, attributes and methods, encapsulation, private variables, inheritance, polymorphism, method overriding, abstraction, abstract classes, `@abstractmethod`, `super()`, and exception handling in OOP.

### NumPy

I learned NumPy arrays, array data types, indexing and filtering, Boolean masks, mathematical calculations, `np.sum()`, `np.isinf()`, string operations using `np.char`, `np.char.startswith()`, converting Pandas columns to NumPy arrays, revenue calculations, negative-value analysis, and cancelled-transaction analysis.

### Pandas

I learned DataFrames, CSV handling, `df.info()`, `df.describe()`, missing-value analysis, duplicate detection, `loc`/`iloc`, sorting, filtering, `groupby`, aggregation, `transform`, pivot tables, `merge`, `concat`, date analysis, ranking, binning/segmentation, and `apply()`.

### Data Cleaning and Quality Analysis

I gained practical experience in identifying missing values, duplicates, invalid data, negative values, inconsistent transactions, date/time issues, incorrect data types, CSV encoding problems, and data-validation issues.

### Business Analysis

I learned to identify revenue trends, top-contributing products and countries, business problems, revenue leakage, customer segments, payment-method patterns, suspicious transactions, and opportunities for offers, discounts, and customer retention.

### Excel

I learned Freeze Panes, data types, COUNT/COUNTA, cell references and absolute references, tables, Text to Columns, TRIM/UPPER/LOWER/PROPER, CONCATENATE/TEXTJOIN/& , LEFT/RIGHT/MID/LEN/FIND, data validation, IF/AND/OR/IFERROR/IFNA, SUMIFS/COUNTIFS/AVERAGEIFS, VLOOKUP/HLOOKUP, INDEX-MATCH, sorting and filtering, UNIQUE/SORT/FILTER/SEQUENCE/RANDARRAY, STDEV.S/VAR.S/QUARTILE/CORREL, FORECAST/TREND, Pivot Tables, Analysis ToolPak, Power Query, Power Pivot, basic DAX, XLSX/CSV handling, and worksheet protection.

### SQL

I practised basic SQL operations including removing data using `DELETE` and retrieving unique values using `DISTINCT`.

### Databricks and PySpark

I learned the fundamentals of Databricks and Apache Spark, Spark DataFrames, creating DataFrames from dictionaries and tuples, defining column names, using `spark.createDataFrame()`, and displaying data with `display()`.

<h2>📌 Project Introduction</h2>

<h3 id="project11">CustomerIQ — Customer &amp; Revenue Intelligence</h3>

<p>
  CustomerIQ is a Customer &amp; Revenue Intelligence platform designed to help businesses analyze customer behaviour, predict customer churn, estimate Customer Lifetime Value (CLV), and identify potential revenue risks.
  The project combines Machine Learning, SQL, FastAPI, Streamlit, and data analytics to convert customer and transaction data into actionable business insights.
</p>

<p>
  The application provides an executive-level dashboard with important business KPIs, customer risk analysis, churn prediction, CLV prediction, and revenue-at-risk analysis.
</p>

<h4>🛠️ Technologies Used</h4>

<ul>
  <li><strong>Programming:</strong> Python</li>
  <li><strong>Data Analysis:</strong> Pandas, NumPy</li>
  <li><strong>Machine Learning:</strong> Scikit-learn, Random Forest</li>
  <li><strong>Database:</strong> SQL</li>
  <li><strong>Backend:</strong> FastAPI, Pydantic</li>
  <li><strong>Frontend:</strong> Streamlit</li>
  <li><strong>Visualization:</strong> Plotly</li>
  <li><strong>Model Serialization:</strong> Joblib</li>
  <li><strong>Deployment:</strong> Render, Streamlit Cloud</li>
  <li><strong>Version Control:</strong> Git &amp; GitHub</li>
</ul>

<h4>📌 Major Application Modules</h4>

<ul>
  <li><strong>Customer Churn Prediction</strong> – Predicts customers who are likely to churn using a Random Forest Classifier.</li>
  <li><strong>Customer Lifetime Value Prediction</strong> – Estimates the potential lifetime value of customers using a Random Forest Regressor.</li>
  <li><strong>Revenue-at-Risk Analysis</strong> – Identifies potential revenue that may be lost due to customer churn and customer risk.</li>
  <li><strong>Executive Summary</strong> – Displays key business metrics including total customers, churn rate, CLV, and revenue at risk.</li>
  <li><strong>Customer Retention Insights</strong> – Helps identify high-risk and high-value customers for targeted retention strategies.</li>
</ul>
